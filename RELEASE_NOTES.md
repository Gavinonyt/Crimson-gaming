# Crimson Gaming 2.3.0
**Release date:** November 19, 2026

## What's new

### American Garage expansion
- Expanded the Crimson Sprint garage with a broad U.S. auto collection spanning modern manufacturers, historic marques, performance builders, electric-vehicle makers, and American truck makers.
- New additions include Buick, Jeep, Ram, Chrysler, Tesla, Rivian, Lucid, Pontiac, Plymouth, Oldsmobile, Mercury, Saturn, AMC, Studebaker, Packard, DeSoto, Hudson, Nash, Kaiser, Eagle, Geo, Edsel, Tucker, Auburn, Cord, Duesenberg, Saleen, Shelby, Hennessey, SSC, Czinger, Fisker, Hummer, Bollinger, International, Mack, Peterbilt, Kenworth, Freightliner, and Western Star.
- Added model entries such as the Buick GNX, Jeep Wrangler Rubicon, Ram 1500 TRX, Tesla Model S Plaid, Cybertruck, Rivian R1T/R1S, Lucid Air Sapphire, Pontiac Trans Am, Plymouth Barracuda, AMC Javelin, Studebaker Avanti, Tucker 48, Duesenberg Model J, Saleen S7, Shelby Cobra, Hennessey Venom F5, SSC Tuatara, and Czinger 21C.
- Added American heavy-duty truck entries, including Mack, Peterbilt, Kenworth, Freightliner, and Western Star.
- New vehicles are available in the existing dealership and can be purchased with Crimson Cash or accessed through existing owner privileges.
- Vehicle catalog entries use the current shared browser-game driving and cabin renderer; unique model-specific 3D assets are not included in this update.

### Platform update
- Updated the website version to **2.3.0**.

## Publishing status
- Website and release notes have been committed to the repository's `main` branch.
- GitHub Pages deployment follows the repository's Pages configuration and may take a few minutes to update.
- This repository integration can commit the release notes, but does not expose a GitHub Releases creation action. An official GitHub Release page/tag has therefore not been created by this update.


## 2.4.0 — American Legends Update
- Expanded the Crimson Sprint dealership with additional American marques and specialist manufacturers, including Willys, Pierce-Arrow, Marmon, Stutz, Franklin, Crosley, Graham, Hupmobile, Panoz, Vector, Mosler, Rezvani, Karma, Aptera, Faraday Future, Mullen, and Elio.
- Added new selectable vehicle entries with individual names, colors, and dealership prices.
- Preserved existing vehicles, garage ownership, and the Miami-inspired Crimson City map.
