# Ultra Launcher 5.0.0
**Release date:** November 21, 2026

## 5.0.0 — Ultra Drive & World Update

### Included in this web release
- Promoted the launcher release identity to 5.0.0 and synchronized the browser title, footer, and in-app changelog.
- Preserved the V4.0 platform theme experience: Ultra, PlayStation-inspired, Xbox-inspired, Wii-inspired, Nintendo Switch-inspired, and Windows 11-inspired modes.
- Kept Ultra City: State of Sun and the browser-playable Ultra Sprint experience accessible from the launcher.
- Carried forward existing game hubs, library, favorites, profiles, friends, social pages, customization, and account sign-in.

### Ultra Drive Connect — in development
- Established the scope for a future vehicle companion covering Apple CarPlay, Android Auto, and supported-vehicle digital-key experiences.
- **Not included as working integrations in this release:** CarPlay projection, Android Auto projection, and real vehicle-key pairing. These require compatible devices and vehicles, approved platform integrations, and manufacturer-supported digital-key APIs. The web launcher cannot independently unlock or start a real vehicle.
- Ultra Drive Connect remains a planned integration area until the required platform and manufacturer access is available.

### Release limitations
- This commit updates the GitHub Pages website source and release notes. GitHub Pages must finish deploying before the live site reflects the change.
- The Android APK and Windows companion installer were not rebuilt in this web-only release. Their binaries remain separate deliverables and should not be presented as updated 5.0.0 installers.
- This release does not claim that third-party gaming-company partnerships exist or that platform interfaces are official software.

# Ultra Launcher 4.0.0
**Release date:** November 20, 2026

## 4.0.0 — Platform Theme Experience
- Expanded the platform theme system with a Nintendo Switch-inspired theme alongside Ultra, PlayStation 5-inspired, Xbox-inspired, Wii-inspired, and Windows 11-inspired modes.
- Refined Wii mode with a bright channel-style navigation rail and tile-focused game library.
- Added a Switch-inspired red/blue console presentation with horizontal navigation and square game tiles.
- Improved Windows 11 mode with a redesigned Start panel, searchable pinned destinations, centered taskbar controls, network indicator, and live clock.
- Persisted the selected launcher theme across sessions and kept the existing library, favorites, category filters, profiles, and game launch actions intact.
- Themes use original Ultra assets and interface styling inspired by each platform's visual language; they are not official platform software or exact reproductions.

# Ultra Gaming 2.6.0
**Release date:** November 19, 2026

## 2.6.0 — Ultra Launcher Hub Update
- Added All, Racing, Creative, Adventure, and Community filters to the launcher dashboard and game library.
- Game cards now match category filters and search terms together.
- The signed-in player's display name appears in the launcher profile area.
- Fixed the launcher settings page heading so its selected view title updates correctly.

## 2.5.0 — Ultra Originals & Cockpit Update
- Added playable browser beta builds for Ultra Drift, Ultra Life, Ultra Quest, Ultra Blocks, and Ultra Racing.
- Added Ultra Launcher as an in-site hub for launching the Ultra Originals.
- Added a dedicated Arcade page and Store launch actions for each title.
- Improved the Ultra Sprint cockpit view with vehicle-family styling, instrument displays, infotainment, climate controls, steering-wheel details, seats, and interior trim.
- Vehicle cabins are stylized game renderings, not exact factory-verified replicas.
