# Ultra Gaming 2.6.0
**Release date:** November 19, 2026

## 2.6.0 — Ultra Launcher Hub Update

### Ultra Launcher game hubs
- Added All, Racing, Creative, Adventure, and Community filters to the launcher dashboard and game library.
- Game cards now match category filters and search terms together.
- The signed-in player's display name appears in the launcher profile area.
- Fixed the launcher settings page heading so its selected view title updates correctly.


## 2.5.0 — Ultra Originals & Cockpit Update

### Ultra Originals beta arcade
- Added playable browser beta builds for Ultra Drift, Ultra Life, Ultra Quest, Ultra Blocks, and Ultra Racing.
- Added Ultra Launcher as an in-site hub for launching the Ultra Originals.
- Added a dedicated Arcade page and Store launch actions for each title.
- Replaced the previous Coming Soon and In Development labels with beta-release labels.
- These are first playable browser builds, not full-scale downloadable desktop games.

### Ultra Sprint vehicle interiors
- Improved the in-game cockpit view with distinct styling for vehicle families, including sports cars, muscle cars, trucks, SUVs, and electric vehicles.
- Added or refined dashboard shapes, instrument displays, infotainment screens, climate controls, steering-wheel details, seat silhouettes, trim, and stitching.
- Interior designs are stylized, vehicle-inspired game renderings. They are not exact, factory-verified replicas of every real vehicle.

## Publishing status
- The website source and release notes are committed to the repository's `main` branch.

## Ultra Launcher 2.7.0 — ValorsHub-inspired interface refresh
- Redesigned the full launcher visual system with a premium dark gaming workspace, violet accent palette, refined navigation, cleaner game cards, and consistent controls across pages.
- Improved responsive layouts, focus states, and reduced-motion accessibility.
- Keeps the Ultra Launcher name and DC branding. This is an original design inspired by modern gaming community platforms, not a copy of another product.


## Ultra Launcher 2.8.0 — Desktop workspace & customization
- Tuned the launcher for wide desktop displays with a dedicated sidebar, wider content canvas, and responsive tablet/mobile layouts.
- Added live custom accent color, compact/comfortable spacing, and solid/glass panel styles.
- Added per-account browser preference saving and a one-click reset to the default Ultra appearance.
- Refined the visual language with quieter surfaces, sharper typography, and restrained highlights for a more intentional custom desktop feel.
